# 🎭 Impacto da Pandemia na Arte e Cultura

Projeto desenvolvido como Trabalho de Conclusão de Curso (TCC) no ensino técnico em Desenvolvimento de Sistemas.

---

## 📌 Sobre o projeto

Este projeto tem como objetivo apresentar e analisar os impactos causados pela pandemia no setor artístico e cultural, destacando mudanças, desafios e adaptações enfrentadas durante esse período.

---

## 🎯 Objetivo

Demonstrar, de forma informativa e acessível, como a pandemia influenciou a produção artística, eventos culturais e o consumo de arte.

---

## 💻 Tecnologias utilizadas

* HTML
* JS
* CSS

---

## 🚀 Funcionalidades

* Exibição de conteúdo informativo sobre o tema
* Estrutura simples e organizada de página web
* Navegação básica

---

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, foram aplicados conhecimentos como:

* Estruturação de páginas com HTML
* Organização de conteúdo
* Desenvolvimento de projeto acadêmico
